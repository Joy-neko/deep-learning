# transformer手写实践
本目录仅用于记录我在学习 Transformer 过程中完成的代码实现，目的在于动手理解transformer原理与架构；
目前主要使用PyTorch对Transformer中的关键模块进行拆解与实现，并借助AI生成相关测试进行结果层面的验证；
本仓库并非完整项目或工程框架；
